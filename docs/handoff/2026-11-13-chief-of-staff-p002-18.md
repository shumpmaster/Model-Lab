## Mechanics learned this session
- A re-check loop on a guard's design can run on: each fix adds design the next Critic finds a new gap in. After the third FAIL, put the choice to the owner (one more pass, or park), and brief the last Critic to keep true blockers (a false statement or a branch with no result) apart from refinements that can be stated as limits or carried on the scenario card.
- Brief text in a bash heredoc: escape every backtick, or a word in backticks runs as a command (brief 321's first commit lost two words this way and was amended before any push).
- `git commit --amend` keeps the old author: pass `--reset-author` when re-signing a merge as the Orchestrator.
- Record a long helper return verbatim by pulling its final text out of the task's output file with a short script, never by reading the file into context.
- Keep the coder of a reading (here `later_work`) off docs/briefs/**, docs/handoff/**, reviews/** and earlier memos, which hold expected results; give the second checker the codes and the same pack.
