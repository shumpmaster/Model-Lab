Milestone: M4

The fair test keeps each secret marking sheet in a private repository, held only by the separate sessions that write it and judge with it, so that no session doing or starting the work can see it.   C. Stop the test — no runs are spent and nothing is exposed. Rules out: the fair test, and with it the changes' measured result.
