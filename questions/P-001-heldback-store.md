# Ruling needed: where the fair test's secret marking sheets are kept

Milestone: M2

The fair test's plan failed its last check before Design closes partly because nothing says where its secret marking sheets are kept. There is one sheet for each kind of work, written by a helper who never learns what is being tested, and used to judge each piece of work blind. The work being judged must never see the sheets, and they must last as long as the test, which may run for over a year. The operating model has never settled this either. There are three choices below. The first needs a few minutes of your time and keeps the sheets out of reach of the work, provided the test's sessions are set up as described. The second needs nothing from you but protects the sheets by instruction only. The third needs your hands at every judging. Any can be changed later, but a sheet that the work may have seen cannot be made secret again: it would be rewritten.

WHY: the plan's fix needs a named place for the sheets before its confirmation review; without one, the sheets cannot be written or checked, and the test cannot start (reviews/S-001/plan.md, "Round 4", finding 2; decisions/questions/P-001-plan-stop.md).
OPTIONS:
  A. A new private repository only for the sheets — Gain: the sheets last as long as the test, and stay out of the work's reach, as long as only the sessions that judge are started with that repository and the sessions that do or start the work never are; a session's repositories are chosen when it starts, and helpers share their session's machine, so this rests on how sessions are set up, which no test has yet shown; and nothing read shows whether the environment's settings add a repository to every new session, which would make A no safer than B, so you would check those settings when you create it. What happens: you create one private repository; each judging session is started separately with it selected, never from the session that starts the work. Cost: one action from you to create it, your approval wherever a session asks to attach a private repository, separate judging sessions, and one more repository to keep for the test's life. Rules out: running judging from the same session as the work.
  B. A folder in your private portfolio repository — Gain: nothing needed from you, no extra session set-up, and the sheets stay in a private store you already own. What happens: the sheets go in a folder there that no helper's reading list includes. Cost: this session, and any like it, holds the portfolio repository, so any helper it starts, including the ones doing the work being tested, could open the folder; the sheets are kept away from the work by instruction only. Rules out: a test whose secrecy does not rest on instruction.
  C. You keep the sheets yourself — Gain: no repository holds them, and only the session that writes each sheet, the one that passes it to you, and the one judging with it see it. What happens: the helper hands each sheet to you once, and you give the one sheet needed to each judging session when it starts. Cost: your time at every judging; at the recommended size of 60 pairs a kind, about 300 judging sessions over the test's life: two a pair for plans and for built work, one a pair for research (specs/S-001.md, AC5). Rules out: judging without you.
  Encrypting the sheets in the portfolio repository is not offered: the key would need a place to live that the work cannot reach, which is this same choice again.
RECOMMENDATION: A — the test's worth rests on the work never seeing its marking sheets; A is the only choice that keeps them out of the work's sessions without your hands at every judging, provided the sessions are set up as described, which the first judging would confirm.
RISK CLASS: R0 (questions/**)   REVERSIBILITY: reversible   BLAST RADIUS: the fair test's secret marking sheets and the sessions that judge with them; a sheet the work may have seen must be rewritten and its fingerprint recorded again
DEFAULT: none (each option needs your own action or acceptance, so none is adopted by default; as decisions/questions/P-001-plan-stop.md, the owner's own choice)   TIMEOUT: none
