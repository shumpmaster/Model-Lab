# Ruling needed: If testing shows that changing the agents' instructions doesn't help, is "leave them as they are" an acceptable result?

Milestone: Discovery-3
Asked in session: session_01QBwHGJH9m3A4Ray7WpHzBo

WHY: The project will test whether changing the instructions agents run on improves their work. A fair test needs "no change" as a possible winner; otherwise the project is set up to change things whatever the evidence says. This sets what counts as success and when the project stops.
OPTIONS:
  A. Yes — finding that changes don't help is a result in itself; the project then records why and stops, or moves to whichever other cause the research points to (for example, how big the inputs are or how work is split).
  B. No — the project must deliver improved instructions; testing chooses which changes, not whether to change.
RECOMMENDATION: A — the model's own rule is that every change is an experiment that can fail, and a test that can't say "no" can't be trusted when it says "yes".
RISK CLASS: R1   REVERSIBILITY: reversible   BLAST RADIUS: the project's value target and stop rule only
DEFAULT: A   TIMEOUT: 168
