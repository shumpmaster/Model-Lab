# Ruling needed: If testing shows that changing the agents' instructions doesn't help, is "leave them as they are" an acceptable result?

Milestone: Discovery-3
Asked in session: session_01QBwHGJH9m3A4Ray7WpHzBo

WHY: The project will test whether changing the instructions agents run on improves their work. This decides whether the project may end without new instructions, and so what counts as success and when it stops.
OPTIONS:
  A. Yes — finding that changes don't help is a result in itself; the project records why and stops, or, by a separate ruling of yours, moves on to another cause the research points to (for example, how large the inputs are or how the work is split). Cost: the project may end with no new instructions to show.
  B. No — the project must deliver improved instructions; testing chooses which changes, not whether to change. Cost: a change may be adopted that testing did not show to help.
RECOMMENDATION: A — the rulebook treats every change as an experiment that can fail, and a test that cannot say "no" is weaker evidence when it says "yes".
RISK CLASS: R1   REVERSIBILITY: reversible   BLAST RADIUS: the project's value target and stop rule only
DEFAULT: A   TIMEOUT: 168
