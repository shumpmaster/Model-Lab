# Research question — Q-013

## The question

What can a trial of a process change on an organisation's own work show with one to a few tens of runs (a run being one piece of work done once under the changed or the unchanged process): what size of effect can it detect, and with what chance of a false result? What does such a trial cost? Compare the designs available for so few runs (for example paired comparisons, sequential or adaptive designs, single-case designs and small-sample Bayesian methods), and how a frozen plan made before the runs, not re-running until a better answer appears, repeated looks at the results, and other changes made to the same work at the same time each affect what a trial can show.

Facts already in the portfolio library (/home/user/portfolio/library/, index in README.md) need not be re-researched: the entries numbered Q-003-* (on measuring agent work with few runs), Q-009-F4-2, F4-3, F4-5 and Q-009-F8-4 to F8-8.

## The decision it serves

Whether outside practices are adopted on evidence alone, after a trial on the organisation's own work, or after a controlled comparison; and whether trials of different changes may run at the same time.

## What each answer would change

If few-run trials cannot separate real effects from noise, adoption rests on whatever other evidence there is; if they can separate only large effects, or only in some designs, a trial can gate only changes expected to matter that much; if they can, a trial can serve as the gate. Evidence on simultaneous changes decides whether trials must take turns or may run together.
