# Research question — Q-004

## The question

How well do written instructions for language-model agents carry over when the model behind a role is replaced by another model or a newer version, and which practices have been shown to reduce any loss or to make no difference? Include evidence that instructions carry over well. Treat replacement by a different model and by a newer version of the same model separately.

The pipeline under study is the operating model in shumpmaster/Personal-Org-Operating-Model (OPERATING_MODEL.md; role definitions in template-v3/.claude/agents/; briefs and packs in template-v3/governance/BRIEFS.toml and PACKS.toml). Treat it as the subject being studied, not as evidence of what works.

## The decision it serves

The Discovery of P-001 (a project on how the written instructions that pass work between the agents of that operating model are written, checked and changed): whether instructions are written and versioned per model, and whether a fixed set of tasks is kept to re-check them when a model changes.

## What each answer would change

Large losses favour per-model versions and a standing re-check; small ones favour one shared set of instructions and checks only on demand.

topics: prompts, models, portability, versioning
